# Outputs

Every graded run is saved here. Open `summary.html` in a run folder for the ranking. SSNs are masked.

| Folder | Made by |
|---|---|
| `web/<date_time>/` | `Start Grader.bat` (the drag-and-drop page) |
| `clients_<date_time>/` | `Grade My Clients.bat` (everything in `inputs/clients`) |
| `sample_clients/` | a run on the fictional sample clients |
| `test_report/` | the test suite's precision/recall and fit-level report |

Nothing in this folder is committed to GitHub except this README.
