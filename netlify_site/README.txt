THE PUBLIC WEBSITE (tax-scan.netlify.app) - fictional sample clients only.

  site\                   the website files
  tax-scan-site.zip       the file to upload to Netlify
  Build Website.bat       rebuilds site\ and the zip after you change the rules or design

To update the live site:
  1. Double-click "Build Website.bat" (about a minute).
  2. It publishes to tax-scan.netlify.app automatically when the Netlify tool is signed in on this PC.
     If not, File Explorer opens on the zip: Netlify > tax-scan > Deploys, drag tax-scan-site.zip onto the page.
