THE PUBLIC WEBSITE (tax-scan.netlify.app) - fictional sample clients only.

  site\                   the website files
  tax-scan-site.zip       the file to upload to Netlify
  Build Website.bat       rebuilds site\ and the zip after you change the rules or design

To update the live site:
  1. Double-click "Build Website.bat" (about a minute). File Explorer opens with the zip selected.
  2. In Netlify open the tax-scan project > Deploys, and drag tax-scan-site.zip onto the page.
